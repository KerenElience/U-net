# U-Net
复现[U-Net论文](https://arxiv.org/html/1505.04597v1#S1)，强化记忆
衍生品复合架构：unet+resnet
进阶版本：unet++、rnn-unet

## 具体细节
- 使用SBD增强数据集，github以及kaggle上都能搜到，原增强数据集提供者的链接已经下架了
- 为方便进行多分类的segment任务将输出层改为可选，将sigmoid改为softmax
- 原文中的下采样方法从图示标注上来看是maxpool，替换为3X3的Conv2d，步长设置为2，padding为1。相对于最大池化，使用卷积进行下采样能提取更多的细节
- 上采样中，原文未提及图像对齐
- 原文中的卷积核采用reflect方式进行padding的，使得一个感受野获取更多的信息
- 架构上面采用了Encoder-Decoder模式
- 作为2015年的文章，在架构上采用了类似Resnet的残差连接方式（上采样中的拼接，跳跃链接）
- 转置卷积是一个可学习的权重，能在网络训练过程自适应找到最佳的采样方式，代价是训练和推理的速度不如插值法
- 转置卷积核使用2x2，能够避免伪影，栅格出现
- Unet在少量的样本训练上就能取得不错的效果，框架简单易懂，缺点是相对于Yolo，VGG，Resnet等网络数据的标注很痛苦，但是相对于Yolo框架来说能够很好的计算识别区域的面积方便后续的精确量化

## 踩坑记录：
### 关于环境搭建(Data Loading)
- albumentationsx版本不兼容
- 安装albumentations 2.0.8版本，对应默认albucore 0.0.16中缺失`MONO_CHANNEL_DIMENSIONS`，查找albucore github issue页面，应该安装0.0.16 ~ 0.0.28及之前的几个版本
- segmentation图像读取不要使用Opencv，只有Pillow能正确读取图像中的标签分类，opencv会将其转换成调色板上的数值失去原本的标签
- 数据增强部分不要让模型开始就太“为难”，增强强度不要太高(考虑现实场景也不会有特别严苛条件下拍摄的图片)
### 关于损失函数
- CrossEntroy + Dice 组合损失函数不要设置分配系数为0.5，会导致模型总是在学习图片中的背景，把所有类别预测为背景，跑出来的Loss是假的(miou极低)，让模型专注于分类Dice。可以前期使用0.2或者0.1，或者干脆只用Dice，后期查看各个分类的iou有不错的值之后在该也行。交叉熵在乎的是整体，而本身图片就大部分是背景（也就是背景与等于整体），所以交叉熵权重过高会诱导模型往背景方向学习。
### 关于训练
- lr_scheduler策略试过warming up+余弦退火、ReduceLROnPlateau，对应优化器使用Adam，效果都不太好，在50~100epoch时学习率就很低了
- 显存不太够，开启了amp，batch_size设置得也很小。
