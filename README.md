# U-Net
复现[U-Net论文](https://arxiv.org/html/1505.04597v1#S1)，强化记忆
衍生品复合架构：unet+resnet
进阶版本：unet++、rnn-unet

## 具体细节
- 使用SBD增强数据集，github以及kaggle上都能搜到，原增强数据集提供者的链接已经下架了
- 为方便进行多分类的segment任务将输出层改为可选，将sigmoid改为softmax
- 原文中的下采样方法从图示标注上来看是maxpool，替换为3X3的Conv2d，步长设置为2，padding为1。相对于最大池化，使用卷积进行下采样能提取更多的细节
- 上采样中，原文未提及图像对齐
- 原文中的卷积核采用reflect方式进行padding的，使得一个感受野获取更多的信息
- 架构上面采用了Encoder-Decoder模式
- 作为2015年的文章，在架构上采用了类似Resnet的残差连接方式（上采样中的拼接，跳跃链接）
- 转置卷积是一个可学习的权重，能在网络训练过程自适应找到最佳的采样方式，代价是训练和推理的速度不如插值法
- 转置卷积核使用2x2，能够避免伪影，栅格出现
- Unet在少量的样本训练上就能取得不错的效果，框架简单易懂，缺点是相对于Yolo，VGG，Resnet等网络数据的标注很痛苦，但是相对于Yolo框架来说能够很好的计算识别区域的面积方便后续的精确量化

## 踩坑记录：
### 关于环境搭建(Data Loading)
- albumentationsx版本不兼容
- 安装albumentations 2.0.8版本，对应默认albucore 0.0.16中缺失`MONO_CHANNEL_DIMENSIONS`，查找albucore github issue页面，应该安装0.0.16 ~ 0.0.28及之前的几个版本
- segmentation图像读取不要使用Opencv，只有Pillow能正确读取图像中的标签分类，opencv会将其转换成调色板上的数值失去原本的标签
- 数据增强部分不要让模型开始就太“为难”，增强强度不要太高(考虑现实场景也不会有特别严苛条件下拍摄的图片)
### 关于损失函数
- CrossEntroy + Dice 组合损失函数不要设置分配系数为0.5，会导致模型总是在学习图片中的背景，把所有类别预测为背景，跑出来的Loss是假的(miou极低)，让模型专注于分类Dice。可以前期使用0.2或者0.1，或者干脆只用Dice，后期查看各个分类的iou有不错的值之后在该也行。交叉熵在乎的是整体，而本身图片就大部分是背景（也就是背景与等于整体），所以交叉熵权重过高会诱导模型往背景方向学习。

整体上来说ResUnet全方位碾压Unet：
1. 上采样后没有进行降通道操作而是直接拼接
2. 训练初始encoder感受野大
3. 采用激进的下采样策略，到瓶颈层维度仅为 512x8x8，节省了大量内存，也为计算提速不少
4. 使用残差链接方式，防止梯度消失，让最底层的encoder也有几乎学习到原始特征
5. resnet使用的是resnet34网络结构，瓶颈层没有采用1x3x1的方式，防止特征丢失过多
6. 特别的，数据增强引入了拉伸变形，矩形块随机消失，随机明亮/对比度/锐化，高斯噪声，用于获取更泛化的模型（为什么原版Unet不用？试过了，本来就笨的Unet加入之后Loss波动更大，miou迟迟无法提升，根本学不到东西）

#### ResUnet-pretrained(decoder attention)
直接将resnet34的预训练权重加载后作为Resunet的encoder部分

```shell
Resunet-pretrained (attention):
best epoch 72
Class_iou: 
[0.8151819705963135, 0.5929291248321533, 0.2145272046327591, 0.6957395076751709, 0.2712303102016449, 
0.5805100798606873, 0.7625992894172668, 0.7045577168464661, 0.7662131786346436, 0.20453806221485138, 
0.5660848617553711, 0.4187239110469818, 0.6705337762832642, 0.5470290184020996, 0.5524162650108337, 
0.6369372010231018, 0.3111366033554077, 0.567618191242218, 0.2927168011665344, 0.650867760181427, 
0.47811880707740784]
Train loss: 0.7720043665512811, Valid loss: 0.5157881217158359, mIoU: 0.5381051898002625
```
1. 从结果上来看，含有预训练的模型要远远由于上面的模型，训练轮次也低于前面的模型；
2. 从训练过程中看，具备预训练权重的模型在早期就具备了一定的分割能力，这得益于resnet34本身在ImageNet上具备的边缘检测能力。此外一些小物体，在第一个轮次时模型就已经捕捉到了一点特征，不像上面探索过的模型为0；
3. 为了契合resnet_weight34，在数据增强时选择使用ImageNet的魔法标准化参数；
4. 训练中encoder和decoder使用了不同的学习率，这只是粗浅的做法，如果要进一步优化可以将encoder不同的layer层以及头部conv层给予不同的学习率，层数约靠前给予的学习率应该越小，因为resnet在当前任务中提取特征的能力是可以通用的；
5. attention最后的输出层经过的是sigmoid，sigmoid将注意力导向0、1两个方向，这仅仅给予了模型区分前景与背景的能力，直观上来说对于模型捕获细小物体的能力会有帮助。
6. 由于使用了Resnet34直接作为encoder层，其中的输入原始通道3就已经是固定结果无法更改了，如果需要更改则应该在resnet34_encoder层前添加一个n_channel->3的卷积层。

总结一下：从原版unet->resnet_unet->resnet_attention_unet->resnet(pretrained)-attention_unet，miou逐级提升，提升最明显的就是引入resnet和引入resnet预训练权重。

神经网络当前个人理解为：根据先验知识，在已知的潜在空间中，通过一定的约束条件获得满足条件的解（集）。再从头来看，encoder由原版换成resnet，提升了获取先验知识的能力，attention将约束条件进一步收束，而预训练权重则是将可迁移的先验知识和潜空间搬运过来极大加快了模型的预测（推理）能力。
